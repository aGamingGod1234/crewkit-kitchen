Non-negotiable behavior

Exact profile

No provider, model, reasoning, or service-tier fallback. Recovery recreates the selected profile exactly.

No dead end

Runtime faults become degraded, retryable, or backoff states. Only explicit shutdown is terminal.

Player intent

Only the player can pause a goal. Infrastructure failures keep active work recoverable.

One of everything

Retries converge to one process, one session, one turn, and one physical action.

Recovery loop

Detect boundary→Fence stale generation→Preserve goal + profile→Retry or roll back→Verify stable→Promote healthy
