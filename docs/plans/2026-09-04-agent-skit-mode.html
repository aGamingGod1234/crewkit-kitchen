Agent Skit Mode

Complete Add persistent company-logo skins to all agent renders and a deliberate, opt-in mode for cinematic summon/placement scripts.

Scope

  • Generate logo-forward skins for ChatGPT/OpenAI, Claude, DeepSeek, Gemini, and Kimi, with a safe fallback for existing providers.
  • Add a separate skit mode toggle that is off by default and does not change normal agent control.
  • Provide concise commands for named summons, current-position placement, exact coordinates, facing angle, and reusable movement sequences.
  • Keep all state server-authoritative and persist mode/placements with the world.

Parallel work

  1. Skin manifest, PNG generation, and renderer lookup.
  2. Skit-mode state, commands, summon/placement, and scripted movement.
  3. Tests, compatibility review, and build verification.

Important decisions

  • Mode is intentionally opt-in through an in-game toggle command.
  • Coordinates accept absolute values and ~ relative notation; rotation accepts yaw/pitch.
  • Scripts are bounded, world-persisted timelines so a skit can be replayed without giving agents autonomous control.

Risks

  • Existing renderer identity keys must remain compatible with current coordinator profiles.
  • Logo marks are rasterized from the referenced online brand sources; the generated textures are bundled locally so the mod never downloads assets at runtime.
  • The branded 512x512 files retain vanilla UV coordinates and are mod resource textures; ordinary player and mob textures keep their native resolution, and these are not intended for the vanilla skin-upload screen.
  • Movement playback is intentionally a staging teleport timeline. It does not simulate Elytra physics or autonomous movement.

Skin files and rendered previews

These are the actual 512x512 branded PNG files from the PR, scaled down only for phone viewing. They preserve Minecraft's vanilla 64x64 UV layout. Most front faces use a 56x56 logo raster with a 4px clear margin; KIMI uses the supplied complete 64x64 black-background face tile. Logos are face-only; bodies and torsos keep their brand base treatment. Tap any "PNG file" link to open or download the source texture from the PR branch.
