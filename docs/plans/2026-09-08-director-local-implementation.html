2. Connect the editorLayout A implemented. Saved-script pickers and pages, seconds-based fields, drafts retained during the connection, take assignments with starting marks, a shared countdown and Stop take. Camera preview closes the editor.
3. Verify local behaviorPassed: local build, 14,961 core assertions, 385 voice add-on assertions and 120 Node voice tests. The final focused run passed 484 Director assertions, including cast reservation and whole-take cancellation. The current local mod JAR was built successfully.

Scope: local work only. Base: existing Director fixes. A separate worktree protects the other runtime changes. Risks: voice completion must return to the server thread; saved content must remain backward-compatible; camera playback is client-local.

Verified headlessly: edits and persistence, stale-write rejection, delayed speech sequencing, failure handling, camera data safety, and reachability of controls in a short window. Live Minecraft rehearsal and audible voice quality have not been tested. Cold speech synthesis may delay the first line; the take does not preload audio.

No PR, push, game launch or deployment is part of this local implementation. This page is the implementation plan and mockup review.
