Agent Arena reliability sweep

Find reproducible failures across the coordinator, Minecraft runtime, proximity voice, client controls, and their shared boundaries. Fix the highest-value issues and leave focused regression coverage.

Completed 30 Aug 20269 parallel auditsStatus: verified

Scope

  • Coordinator lifecycle, scheduling, provider handling, and ArenaScript execution
  • Protocol framing, reconnects, ordering, backpressure, and malformed input
  • Agent persistence, server restarts, action cancellation, navigation, combat, and perception
  • Client control state and proximity voice lifecycle
  • Build, CI, platform behavior, resource cleanup, and missing reliability tests

Method

  1. Fetch GitHub and preserve local work.
  2. Run independent read-only audits with file ownership split by subsystem.
  3. Reproduce findings with short deterministic tests. Reject findings that code or tests disprove.
  4. Fix severe and likely failures with the smallest safe changes.
  5. Run subsystem tests, full coordinator tests, Gradle verification, and diff checks.
  6. Review the final patch for cross-system regressions and report deferred risks.

Decisions

  • Existing staged and untracked files remain protected unless a verified fix must touch them.
  • No visual application control or live multiplayer interaction without explicit permission.
  • Tests must catch a named failure, not merely add broad smoke coverage.
  • High-impact correctness, recovery, and resource leaks outrank cosmetic cleanup.

Result

  • Made action cleanup recoverable, input leases transactional, timeouts safe across clock rollback, cross-dimension actions fenced, and failed inventory interactions reversible.
  • Isolated multiplayer speech backoff, preserved provider rate-limit signals, made voice warmup degrade per channel, and retained speech-time audience boundaries.
  • Preserved client preferences and scenario rosters through fallback catalogs, blocked stale launches, and removed unsafe unnamed-summon auto-selection.
  • Added locked coordinator dependencies, pinned verified Node.js packaging, transactional distribution updates, omitted verification groups, and Windows/Linux reliability CI.
  • From a clean checkout: 1,221 coordinator tests passed with 2 intentional skips, 14,290 core/protocol/bridge assertions passed, and 277 voice-addon assertions passed.
  • The CI-equivalent Java 25 package build passed, all 119 embedded coordinator files were verified, and distribution rollback plus startup preflight checks passed.
