Decisions

Extend ArenaScript watchers and persistent memory tools. Separate observed facts from agent-written interpretations. Survival handlers execute only authored actions; unhandled danger releases unrelated input for a fresh decision. Notes may be explicitly shared. Historical routes and drops require current verification. Base instructions and the shared API reference stay within existing size limits.

Risks and limits

The model must author useful defenses and choose whether recovery is worthwhile. Remembered paths can change and drops can disappear. Summaries are bounded and expose omissions. Execution and memory checks passed, but natural combat, actual drop recovery, the long diamond-pickaxe task and arbitrary-seed game completion remain unverified with live models.
