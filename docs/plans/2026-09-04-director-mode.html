PR #32 expansionDirector mode

Make skits feel like a tiny film set

Expand the opt-in skit workspace into a director workflow for repeatable actor blocking, timed gameplay actions, proximity-voice dialogue, and smooth camera shots, while leaving ordinary agent control and ordinary player/mob rendering unchanged.

Scope

Actors

Place by crosshair, current position, relative offsets, and look-at targets. Add timeline actions beyond teleport poses.

Voice

Choose a voice profile per agent, set delivery controls, and schedule exact dialogue cues through the optional voice add-on.

Camera

Record camera keyframes in-world and replay them with bounded smooth interpolation for simple cinematic shots.

Safety

Keep the mode explicitly enabled, server-authoritative, world-persisted, bounded, and independently stoppable.

Implementation sequence

  • Define compatible persisted director data and command vocabulary.
  • Add intuitive actor placement and action timeline primitives.
  • Connect voice profiles and speech cues to the existing authenticated TTS worker and Simple Voice Chat sender.
  • Add camera path capture/playback without replacing normal player camera control.
  • Run focused Java/voice verification, document the in-game workflow, and refresh the mobile gallery.

Important decisions

  • Director timelines are deterministic and server-owned. They do not create a second AI control protocol.
  • Actions that need real Minecraft physics remain explicit and fail closed. A teleport pose cannot pretend to be a real elytra flight.
  • Voice remains optional. Without the voice add-on, text staging and camera playback continue and speech reports a bounded unavailable state.
  • Camera interpolation is bounded by keyframe count and duration so a recording cannot create an unbounded tick workload.

Risks and verification

Simple Voice Chat APIs and Minecraft camera ownership are integration boundaries. The implementation will preserve the existing fallback behavior, test serialization and stop/restart paths, and avoid claiming smooth physics where the runtime only has discrete actions.

Delivered command surface

  • /codex skit place ... relative and look_at make actor blocking faster.
  • /codex skit script action ... adds move, wait, jump, equip, use, swing, and emote cues.
  • /codex skit voice ... selects a catalog voice, tone, speed, radius, and timed dialogue.
  • /camera path ... records and smoothly replays client-local cinematic paths.

Status: implemented and verified in the open PR.
