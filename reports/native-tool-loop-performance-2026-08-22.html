What changed

  • One persistent thread per agent keeps the exact selected provider, model, reasoning effort, and service tier.
  • A short bootstrap replaces the long planner prompt and output schema.
  • Compact events include the current goal, player state, inventory, nearby blocks, entities, and recent conversation.
  • Tool requests stream out before the model turn ends. Each exact result returns into that same turn.
  • Skills, connectors, MCP servers, shell, browser, computer use, plugins, repository context, and model fallback are disabled for native agent threads.
  • The body performs pathfinding, action timing, correlation, cancellation, and factual completion checks without making strategic decisions.

Player control coverage

Common actions have small direct tools: observe, moveTo, mine, say, and wait. A strict act tool exposes every remaining production body action, including crafting, block placement, inventory transfer, combat, flee, follow, item pickup, interaction, equipment, menus, building sequences, elytra, and respawn. finish uses server-side factual verification rather than trusting a model claim.
